**Micro-ActInf** is an ultra-lightweight, zero-allocation C11 engine that extracts the pure computational essence of Active Inference and Partially Observable Markov Decision Processes (POMDPs). Occupying exactly **20.75 KB of RAM** and executing in **~3 microseconds**, it solves state tracking and regime management for both real-time game bots and autonomous coding agents.
